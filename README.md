# Laravel Ecommerce API

A scalable ecommerce backend API built with Laravel featuring authentication, product management, shopping cart, and order processing.

---

## 🚀 Features

- User Authentication
- JWT Authentication
- Product Management
- Category Management
- Shopping Cart
- Order Management
- RESTful APIs
- Secure API Routes
- Database Migrations & Seeders
- Product Analytics
- Chatbot

---

## 🛠 Tech Stack

- Laravel
- PHP
- MySQL
- JWT Auth
- REST API
- Composer

---

## 📋 Requirements

- PHP >= 8.3
- Laravel 13
- Composer
- MySQL

---

## 📂 Project Structure

```bash
app/
bootstrap/
routes/
database/
config/
resources/
```

---

## ⚙️ Installation

```bash
Clone the repository
Navigate to project folder
Install dependencies
Copy environment file
Generate application key
Configure database
Run migrations
Start development server
```

---

## 🔐 Authentication

This project uses Laravel Sanctum and JWT authentication to provide secure API access for Vue.js and FastAPI integrations.
